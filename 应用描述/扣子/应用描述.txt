字节跳动旗下AI办公伙伴

扣子全新进化，从单兵作战的智能助手，升级为多人多 Agent 共同在场的工作空间。扣子为你打开了下一代团队形态的大门——欢迎来到 AI Native 团队的协作主场！

在这里，你可以围绕一个项目组织不同 Agent 分工推进，也可以用行业技能包获得专业能力支持。无论是从一个灵感生成视频，还是从一句需求开发应用，扣子都能支持你把想法推进成结果。

- 多人多 Agent 协作：开启全新 Agent 协作方式，一人+多 Agent / 多人+多 Agent 灵活组合，@一下全员就位。多项目独立管理，资料自动沉淀，让团队协作更有序。
- 专业伙伴，开箱即用：Coze Agent 持续满配在线，主流模型自由切换，长期记忆+工作台，越用越懂你；从开发到上线，在编程项目中轻松完成；从灵感到成片，在视频项目中尽情创作
- 你的 Agent，你来定义：本地 Agent 开放一键接入，参与协作；精品行业模版，创建专家 Agent
- 行业技能，攻克难题：为复杂场景而生，自媒体、法律、金融、互联网、科研教育，轻松加载行业专属技能，为垂直行业难题提供解决思路
- 跨端同步，持续推进：桌面端全新上线，可授权 Agent 处理本地文件；App 端同步升级，编程/视频项目手机随时推进；跨端内容同步，用手机遥控处理本地电脑文件
